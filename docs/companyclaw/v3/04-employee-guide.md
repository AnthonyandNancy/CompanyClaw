# 04 — 员工使用指南

- 更新时间：2026-10-09
- 适用范围：公司 Windows 11 电脑上的普通员工账号
- 本文件**不得**出现要求员工执行 npm / PowerShell / 编辑 JSON 的步骤（V3 §16.1 第 5 条）

## 一、安装（一次）

1. 拿到一个安装包 `CompanyClaw-Setup-<版本>-x64.exe`。
2. 双击安装。安装过程**不需要管理员权限**，也不会修改系统环境变量。
3. 如果 Windows 提示"未知发布者"：当前内部技术预览**未签名**，这是预期现象；正式推广版本会由公司签名。

安装完成后从开始菜单或桌面快捷方式打开 **CompanyClaw**。

## 二、首次使用：四个步骤

打开后，向导会依次引导你完成四件事，每步都用中文说明，不需要打开任何命令行窗口。

### 第 1 步：环境自检

程序自动检查本机运行环境，逐项显示结果：

- **正常**：这一项没问题。
- **注意**：能用，但有需要留意的信息（例如远程操作尚未开启）。
- **异常**：这一项有问题，界面会给出中文原因。
- **未检测**：还没测过（例如你还没填 API Key，所以无法判断模型能力）。

如果显示异常，点"重新检测"；仍然异常时把界面文字截图发给 IT 联系人，**不要**自己去安装任何软件。

### 第 2 步：我的模型

1. 选择模型服务来源（默认已预置 DeepSeek 常用地址）。
2. 填入**你自己**的 API Key。
3. 需要时展开高级选项，填写自定义 API 地址与 Model ID。
4. 点保存时程序会做一次连接与能力自检，并告诉你三种结果之一：
   - **支持工具调用**：这个模型可以驱动浏览器与 Windows 操作。
   - **能力未验证**：能聊天，但没测出工具调用能力，远程操作可能无法完成。
   - **不支持工具调用**：只能聊天，无法执行电脑操作。

> 你的 API Key 保存在本机用户目录下，不写入安装目录，也不上传到任何服务器。

### 第 3 步：绑定微信

1. 点"绑定微信"，界面会显示官方二维码。
2. 用**你自己的微信**扫码并在手机上确认。
3. 扫码状态会显示：等待扫码 / 已扫码待确认 / 已绑定 / 二维码已过期（可刷新）。
4. 绑定后可以先用微信给自己的 Claw Bot 发一条普通消息试试收发是否正常。

> 绑定的是**本机当前 Windows 账号**的 Gateway。换人使用或换电脑时请先解绑（见下）。

### 第 4 步：开启远程操作

**默认关闭**，必须由你本人手动开启。开启前请理解：

- 只作用于**当前 Windows 登录账户**；
- 电脑必须保持开机并处于可交互状态（锁屏、睡眠、注销时远程操作不可用）；
- 只允许已授权的系统与程序；
- **关键修改需要在微信上由你本人确认**后才会执行。

选择有效时长后点"开启远程操作"。你可以随时在本机关闭它；关闭后排队中的任务不会再执行新的动作。

## 三、日常使用

用你自己的微信给 Claw Bot 发自然语言指令即可，例如"帮我看看今天有哪些工单""把上个月的报表导出来发我"。程序会在你已授权的范围内操作电脑并把结果发回微信。

- **需要你确认时**：微信会收到一条包含"系统 / 记录 / 字段 / 原值 → 新值 / 有效期"的确认消息。按提示回复（例如 `Y`、`N`、`Y1`、`N2`、`批准第2项`）即可；含糊的回复不会被当作确认。
- **文件回传**：导出的报表会作为文件发到你的微信。界面上的状态含义是：**已提交发送**（平台已受理，未确认送达）/ **发送结果未知**（可能已发送，请先确认再决定是否重发）。
- **任务中心**：在桌面端可以看到任务列表、当前状态、待审批事项，以及暂停 / 继续 / 取消 / 紧急停止。

## 四、常见问题

| 现象 | 含义与处理 |
|---|---|
| 微信里没收到回复 | 确认电脑已开机且未锁屏、微信已绑定、远程操作处于开启状态 |
| 提示"微信插件未安装" | 重新运行安装包选择"修复"，或联系 IT |
| 提示"运行资源缺失/损坏" | 重新运行安装包修复安装，**不需要**自己安装任何组件 |
| 模型能聊天但做不了操作 | 该模型可能不支持工具调用，按第 2 步的检测结果更换模型 |
| 操作到一半停下来 | 可能需要在微信确认，或窗口被切换/锁屏了；查看任务中心的状态 |
| 想暂停远程操作 | 第 4 步点"关闭远程操作"，或在任务中心暂停/取消任务 |

## 五、解绑与数据

- **解绑微信**：在渠道设置里解绑；解绑后原微信号**不能再**启动任务。
- **卸载**：默认**保留**你的配置、API Key、微信绑定与任务记录；如需彻底清理请按 IT 指南操作。
- 你的模型 Key、微信登录态、任务产物都保存在本机用户目录下，按 Windows 账户隔离，同一台电脑的其他账号看不到。
