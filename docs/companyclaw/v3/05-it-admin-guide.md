# 05 — IT 管理员指南

- 更新时间：2026-10-09
- 适用对象：公司 IT / 安全管理员
- 配套文件：`03-packaging-guide.md`（构建）、`04-employee-guide.md`（员工）、`06-release-evidence.md`（验收证据）

## 一、分发与安装

- 分发物：单个 `CompanyClaw-Setup-<版本>-x64.exe`（NSIS，**Per-User**）。
- 安装位置：当前用户目录（`%LOCALAPPDATA%\Programs\CompanyClaw` 一类），**不请求管理员权限**，不写入系统级 PATH，不写 `C:\Program Files\nodejs`，不执行隐式全局 npm 安装。
- **不添加 Defender 排除项**，不关闭任何 Windows 安全设置，Broker 也不以管理员或 SYSTEM 权限运行。
- 员工机器**不需要**预装 Node / npm / Python / Git / .NET SDK / OpenClaw；全部组件随包分发（见 `03-packaging-guide.md` 的资源清单）。

## 二、员工设备与账号

| 操作 | 位置 | 说明 |
|---|---|---|
| 查看绑定状态 | 渠道设置 → 微信插件 | 显示已安装 / 已启用 / 已登录 |
| 解绑微信 | 渠道设置 → 微信插件 → 解绑 | 解绑后该微信号**不能再**创建或驱动任务 |
| 查看/撤销远程授权 | 任务中心 → 远程操作授权 | 默认关闭；可设有效期；关闭后不再派发新动作 |
| 查看任务与审批 | 任务中心 | 任务状态、待审批、产物与回传状态 |
| 紧急停止 | 任务中心 | 停止后续调用并尝试中断可安全终止的动作，**不承诺撤销已提交的业务操作** |

**数据隔离**：模型 API Key、微信登录态、任务、审批记录、浏览器工作 Profile、任务产物均位于该 Windows 账户的用户数据目录（`%APPDATA%` 下的应用数据目录与 `%APPDATA%\openclaw`），按 SID 隔离；同一台机器的其他账户不可读。安装目录只存分发资源，不存任何凭据。

## 三、远程写入授权与浏览器白名单

- **浏览器白名单**：默认**拒绝所有域名**；需在任务中心显式添加允许访问的域名（支持子域，按点边界匹配，`evil-oa.example.com` 不会匹配 `oa.example.com`）。下载与上传是**独立开关**，默认关闭。
- **R0–R3 分级**：只读需有系统级无副作用依据；普通点击**不算**只读；写操作需一次性审批票据；删除 / 付款 / 发布 / 系统配置 / 注册表 / 任意命令 / 未知程序 / 绕过安全 → **恒拒绝**，无开关可放开。
- **可自动化的应用**：Broker 初始**拒绝所有进程**，需显式添加允许的进程与窗口标题。
- 对**无法可信拦截保存动作**的未知业务系统，只允许受限探索；不要批准生产环境的无人值守写入。

## 四、日志与诊断

- 应用日志位于用户数据目录，**默认不含** API Key、完整微信 token、cookie 与会话内容；诊断信息请脱敏后再外发。
- 运行资源完整性：应用启动时会校验包内 `runtime-manifest.json`（逐文件 SHA-256），失败时以中文提示"请重新运行安装包修复安装"。
- 组件健康：首次向导第 1 步与任务中心按组件分别显示（Gateway / 鉴权 / 资源清单 / 插件 / Broker / 浏览器 / 模型），不要用单项"正常"推断整体可用。

## 五、升级、回滚与数据保留

- **升级**：直接运行新版本安装包。升级前会校验：入包 manifest 契约可理解、且磁盘上的数据 schema 不高于本版本可读的版本；任一不满足则**拒绝升级并保留旧安装**，而不是在无法读取的数据上重装。
- **保留内容**：模型 API Key、微信绑定与 token、审批日志、任务历史、浏览器工作 Profile、任务产物，升级与回滚均**不重置**。
- **卸载**：默认保留用户数据；只有显式选择"清理本产品数据"时才删除本产品明确所有的数据，不会清理共享的 `~/.openclaw` 或员工其他项目。
- **不做什么**：不静默重装、不删除用户数据来"修复"问题。

## 六、已知限制与未验证事项（如实告知）

- **签名**：内部技术预览未签名；正式推广需公司代码签名证书，否则会触发 SmartScreen / IT 策略提示。
- **不可用状态**：Windows 未登录、锁屏、UAC 安全桌面、会话断开、RDP 断开时，桌面自动化能力不可用；这些情况下系统返回失败或等待，**不会**伪造"已执行"。
- **未实测项**：清洁机安装、双员工隔离、真实微信收发、内网业务系统写入、升级回滚等，因缺目标环境与账号仍为 `BLOCKED`/`UNVERIFIED`，详见 `06-release-evidence.md`。在这些项实测通过前，不要按"全功能可用"对外承诺。
- **审批语义**：桌面显示"已提交发送"仅表示平台受理，不等于对方已收到；无官方送达回执时不宣称已送达。

## 七、给 IT 的验收清单（放行前）

1. 在**普通非管理员**账户的干净 Win11 上双击安装，全程无 npm/pip/git 下载。
2. 首启四步走完，不出现任何命令行或 JSON 操作要求。
3. 任务中心能分别看到各组件健康状态。
4. 未授权的域名/程序/命令被拒绝，且拒绝发生在执行层（不是仅提示词拒绝）。
5. 解绑微信后，原 sender 不能再启动任务。
6. 升级到新版本后，API Key、微信绑定、任务历史仍在。
7. 卸载默认保留数据。
