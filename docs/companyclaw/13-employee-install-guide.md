# CompanyClaw 员工安装与使用说明

> 面向**不懂技术的普通同事**。全文不含命令行步骤——如果任何一步要求你安装 Node、Python、.NET、Git 或执行 npm/npx，那都是产品缺陷，请直接反馈。

---

## 一、安装（约 2 分钟）

1. 从公司内部分发渠道下载 `CompanyClaw-Setup-<版本>-win-x64.exe`。
2. 双击运行。安装是**当前用户（Per-User）**方式，**不会**要求管理员权限，也不会写入 `C:\Program Files`。
3. 若 Windows 弹出"Windows 已保护你的电脑"提示，点"更多信息"→"仍要运行"。
   （这是未签名内部试用包的正常提示；正式推广包会带公司代码签名。）
4. 安装完成后，从开始菜单或桌面快捷方式打开 **CompanyClaw**。

安装包**自带全部运行环境**（私有 Node 运行时、OpenClaw 网关、Windows 执行服务、Office 技能等）。
你的电脑**不需要**预装任何开发工具。

安装位置：

```
%LOCALAPPDATA%\Programs\CompanyClaw\
```

个人数据（模型配置、微信绑定、任务与产物）保存在用户数据目录，**不在安装目录内**：

```
%APPDATA%\CompanyClaw\
```

---

## 二、首次配置（只需两步）

打开应用后会直接进入配置向导。

### 第 1 步：填写你自己的大模型

| 项目 | 说明 |
|---|---|
| API 格式 | 一般选 `Chat/Completions（兼容 OpenAI）`；用 DeepSeek 保持默认即可 |
| Base URL | 例如 `https://api.deepseek.com/v1` |
| API Key | 你自己的密钥，只存在本机、只供本机使用 |
| 模型名称 | 例如 `deepseek-chat` |

点击"保存并进入系统"后，应用会自动做一次**能力自检**并显示结论：

```
工具调用：支持 / 不支持 / 未验证（不可假定可用）
图片理解：…
推理模式：…
结构化输出：…
```

> **请留意"工具调用"这一项。** 只有它显示"支持"时，Agent 才能操作电脑与浏览器。
> 若显示"不支持"，请换一个支持工具调用的模型；若显示"未验证"，说明这次探测没能得出结论（例如网络问题），可以重试。

### 第 2 步：微信扫码绑定

在向导中点"绑定微信"（或进入"设置 → 频道"），用**手机微信扫一扫**页面上的二维码。
扫码成功后，界面会显示已绑定的微信账号。

绑定完成后，你就可以在**自己的微信私聊**里给 CompanyClaw 发消息下指令。

---

## 三、日常使用

- **发指令**：在微信私聊里用自然语言描述任务，例如"打开工单系统查一下编号 12345 的状态"。
- **授权范围**：默认**不**允许远程操作电脑。需要时在任务中心打开"远程授权"，可随时一键停止。
- **审批**：涉及**修改业务数据**的动作不会自动执行。你会先收到一条审批消息，
  按提示回复确认后才会执行；执行后应用会重新读取目标记录以证明改动真的生效。
- **结果回传**：任务产出的 Excel/PDF 等文件会通过微信回传给你本人。
- **暂停与急停**：任务中心可暂停、恢复、取消或紧急停止正在执行的任务。

## 四、常见问题

**Q：需要我自己装 Node.js / Python / Git / .NET 吗？**
不需要，永远不需要。全部运行环境都已在安装包内。

**Q：应用显示"运行资源校验未通过"怎么办？**
重新运行一次安装包修复安装即可（不会丢失你的模型配置、微信绑定与任务数据）。

**Q：二维码过期了？**
页面会自动刷新二维码，重新扫码即可。

**Q：关闭窗口后应用还在运行吗？**
应用会最小化到系统托盘，网关与执行服务继续工作，以便你从微信下指令。
如需完全退出，右键托盘图标选择退出。

**Q：锁屏或睡眠时还能用吗？**
Windows 的安全桌面（锁屏、UAC 提示）无法被自动操作，这是系统保护机制，应用**不会**尝试绕过。
请保持电脑解锁并处于可用会话。

**Q：可以直接删掉安装目录来卸载吗？**
不建议。请在"设置 → 应用"中用卸载程序卸载。卸载**默认保留**你的个人数据；
如需清除，卸载时会二次确认范围。

---

## 五、卸载

1. Windows 设置 → 应用 → 已安装的应用 → CompanyClaw → 卸载。
2. 默认保留个人数据（模型配置、微信绑定、任务记录）。
3. 如需一并清除，请在卸载提示中明确选择，并确认清除范围仅限 CompanyClaw 自己的数据。

卸载**不会**影响你电脑上已有的其他程序，也不会卸载任何系统级 Node/Git 等组件
（因为安装时就没有安装过它们）。

---

## 六、给 IT 管理员

- 安装范围：Per-User，`%LOCALAPPDATA%\Programs\CompanyClaw\`；`perMachine: false`、`allowElevation: false`。
- **不新增 Windows Defender 排除项**（安装器默认不修改任何主机安全配置）。
- 执行服务（Broker）以**普通用户**身份运行，仅监听本机回环地址，且需要短时令牌。
- 未签名内部包的 SHA-256 清单随发布说明提供；正式推广前将替换为已签名产物。
- 资源完整性：安装目录内 `resources/runtime-manifest.json` 记录每个运行时组件的 SHA-256，
  应用每次启动校验一次，异常时提示修复安装。
